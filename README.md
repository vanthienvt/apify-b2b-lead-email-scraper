# B2B Website Email, Phone & Social Lead Enricher (Apify Actor)

High-speed, zero-browser overhead B2B Lead Enrichment Actor for the **Apify Store**.

## Features
- Crawls company homepages plus `/contact` and `/about` subpages automatically.
- Extracts verified business **Emails**, **Phone Numbers**, **LinkedIn**, **X/Twitter**, **Facebook**, **Instagram**, and **TikTok** profile links.
- Ultra-low compute usage (< $0.001 per 100 websites) for 90%+ creator profit margin on Apify Store monthly rentals.

## Monetization Setup on Apify Store (3 Clicks)
1. Go to [Apify Console](https://console.apify.com/actors) and sign in with GitHub (`vanthienvt`).
2. Click **Create new -> Link Git repository** and select `https://github.com/vanthienvt/apify-b2b-lead-email-scraper`.
3. Click **Build**, then go to **Publication -> Monetization** and set Rental Price to **$19.00 / month**.
